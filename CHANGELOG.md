# Changelog

Todas as alteracoes relevantes deste projeto serao documentadas neste arquivo.

## [1.0] - 2026-09-16

### Adicionado

- Visualizador desktop de Markdown para Windows em WinForms.
- Preview com layout de pagina estilo Word.
- Tema claro e escuro.
- Modo codigo editavel com salvamento do arquivo `.md`.
- Realce de sintaxe para HTML, XML, SQL, PHP, JavaScript, JSON, CSS, C#, PowerShell e variaveis de ambiente.
- Exportacao para PDF pela janela de impressao do Windows.
- Icone proprio do aplicativo.
- Script de build PowerShell.
- Documentacao para publicacao no GitHub.
